文本收起 EllipsisExpand

多行文本超出后以「展开/收起」切换，交互已内置；文本很短时按钮自动隐藏。行数经 --ellipsis-lines 覆盖，默认 3 行。

形态 Variants

这是一段用于演示的正文，内容写得足够长，以便在多行排布时超过默认三行高度，触发省略号截断并显示「展开」按钮。点击按钮可查看完整文本，再点「收起」回到省略态；展开与收起均由组件库内置交互接管，无需在页面上额外编写脚本，也无需手动绑定事件。

通过内联 --ellipsis-lines 覆盖展示行数，这段内容被有意写得比较长，让它在第二行处就出现省略号，从而验证省略行数可以按需调整，以满足不同场景与密度的展示需求。

较短文本未超出设定行数时，按钮自动隐藏。

后缀样式：省略号与「更多」按钮同行显示、不另起一行，适合卡片标题或段落的紧凑布局。这段内容被有意加长，以便在按钮预留宽度内仍然超出默认三行，从而于最后一行末尾紧跟显示「更多」按钮。

类 API 与结构模板 Class API / Structure
类名说明
.ellipsis-expand容器；行数经内联 --ellipsis-lines 覆盖（默认 3）
.ellipsis-expand-content多行省略正文（line-clamp）
.ellipsis-expand-btn展开/收起按钮；未溢出自动隐藏；交互已内置
.ellipsis-expand.expanded展开态
.ellipsis-expand.suffix后缀式：按钮紧跟文本省略号、不另起一行；按钮文案经 data-more/data-less 覆盖
<div class="ellipsis-expand">
  <p class="ellipsis-expand-content">正文…</p>
  <button type="button" class="ellipsis-expand-btn" aria-expanded="false">展开</button>
</div>
