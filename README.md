# sloped — 组件库项目

面向 AI 生成页面的组件库工作区。核心工作流：**design.md（规范源）→ 组件库页面（实现/验收）→ 快照生成业务页**。

## 目录职责

| 路径 | 作用 | 维护方式 |
|---|---|---|
| `design.md` | **AI 规范源**：契约、tokens、注册表、页面骨架、准入规则。**冷启动先读 §0**（快照流程 / 内容纪律 / 自检清单 / 信息流向） | 与组件库同步维护；两者冲突时以 HTML **标记区**实现为准，**并把差异视为需修复同步的 BUG**（见文件开头声明） |
| `组件库设计规范.html` | 运行文件：组件库页面，双击即开。`<style>` / `<script>` 内共 **6 对标记区**：`DESIGN-TOKENS` / `COMPONENTS-CSS` / `COMPONENTS-JS` 为**快照三区**（原样内嵌到生成页）；`DEMO-STYLES` / `GALLERY-CSS` / `GALLERY-JS` 仅本页自用、**不进快照禁止复制** | 改组件样式进 `[COMPONENTS-CSS]` 且只允许引用 `[DESIGN-TOKENS]` 的 token；新增组件按四联同步（design.md §0.1 / 组件补全计划.md §四） |
| `组件补全计划.md` | **历史规划文档**：对照 Ant Design/Semi 的缺口分析与 7 批入库计划（B1~B7 已全部完成，v1.0.0 收官） | 归档留存，不再按批执行；v1.x 维护期的当前进度见下方「当前状态」 |
| `references/` | 线上截图原料区：图 + 同名 `.md` 描述 + `_index.md` 索引 | 新增截图必配描述并登记索引 |
| `pages/` | AI 生成的业务页面归档（自包含单文件）；**首个产物已落地**：`新增用户限流配置-弹窗.html`（v1.6.4 快照；设计源已升 v1.6.5，**重新生成即获修复**，存量产物按 §0.5 不反向修改） | 生成后归档，命名含业务主题 |

## 快速开始

1. 双击 `组件库设计规范.html` 浏览组件与规范；
2. 让 AI 生成页面时，提供 `design.md` + 本文件路径，按 design.md §0 快照流程执行；
3. 新增线上截图 → 放 `references/` → 按 `_spec-template.md` 写同名描述 → 登记 `_index.md`。

### 端到端验证（2026-11-26，v1.6.4 后生成 / v1.6.5 复核）

以 `references/新增用户限流配置-弹窗.md` 为输入，按 §0.2 五步两段式生成首个业务页。快照三区原样内嵌、零外部依赖、零内联事件；浏览器实测 Modal 开合 / Esc / 遮罩 / 联动回填 / 条件字段 / 时间段增删 / Toast 全通过，500 / 900 / 1440px 三档零横向溢出。**此前四轮只打磨「源」，这是第一次跑通「源 → 产物」链路。**

首次生成同时暴露 4 个组件层疑点，按 §0.5「产物永不反向修改源」**未在生成页里修源**。v1.6.5 已用浏览器探针逐项复核并回修设计源（**3 项真实缺陷已修，1 项更正为误报**）：

| 级别 | 疑点 | 复核结论 | 处理 |
|---|---|---|---|
| **P0** | 快照区 `@media` 断点写在 `.grid-cols-2/3/4` 基础定义**之前**，同优先级被后者覆盖；§3.5 的「≤1100 降 2 列 / ≤600 降 1 列」**从未生效** | ✅ 属实。探针实测 500px 下栅格仍 4/3/2 列、`.descriptions` 已 1 列（其基础定义在断点前，故正常） | **已修**：断点块移到 `[COMPONENTS-CSS]` 区末；实测 500px 全部降 1 列，1440px 桌面 4/3/2/3 列零变化 |
| **P1** | `.modal` 的 `visibility` 过渡让部分后代卡在 hidden | ❌ **误报**。双视口 + 20ms 步长采样：仅 t=0 同步读取为 hidden，13ms 起恒 visible；属 CSS `visibility` 过渡在 t=0 取起始值的规范行为，人眼无感。「空白白板」是 headless 同步截图假象 | **源侧 CSS 零改动**；产物 `.biz-modal-wide *` 兜底保留但不作为源缺陷 |
| **P1** | §4.7 声明「关闭后焦点返回触发器」，`[COMPONENTS-JS]` 未实现 | ✅ 属实（文档虚报）。Esc 后 `activeElement = BODY` | **已修**：`openOverlay` 记录触发器、`closeOverlay` 解锁后 `.focus()`；实测 `focusReturned = true` |
| **P2** | `.row` / `.col` 的 `display` 盖过 UA `[hidden]{display:none}` | ✅ 属实。`.row/.col/.flex/.grid/.space` 带 `hidden` 时仍 `display:flex/grid` | **已修**：快照区② 顶部补 `[hidden]{display:none!important}`；实测 5 类全部 `display:none` |

生成页按 §5 把「中宽 Modal / 双列表单 / 周期时间规则块」以 `.biz-*` 落地（未入库，待第 2 次复用），`references/_index.md` 已登记落地点。产物为 v1.6.4 快照，**按项目惯例存量页面重新生成即获修复**，不反向修改。故下一步优先级调整为：**全库边界态覆盖率盘点校准「剩余 X 个」→ 补 3 个已确认的演示缺口（progress 线形 warning / table 排序三态 / empty 纯文案态）→ 按同一矩阵推进下一批边界态演示**。
